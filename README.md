# Construrota

Painel responsivo para organizar entregas de uma loja de materiais de construção.

## Prévia

https://construrota.vercel.app

## O que já dá para testar

- Visão geral da operação e da rota em andamento
- Lista de entregas com filtros e busca
- Cadastro de entrega de demonstração
- Tela de acompanhamento do pedido
- Layout adaptado para celular e desktop

## Rodar localmente

Abra `index.html` no navegador. O protótipo não precisa de dependências ou etapa de build.

## Estado atual

Esta versão é um protótipo de interface: os pedidos de teste ficam no armazenamento local do navegador. GPS real, contas de usuário, sincronização entre dispositivos, notificações de WhatsApp e integração fiscal precisam de backend e integrações antes do uso operacional.
